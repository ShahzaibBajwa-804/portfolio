About

I'm in the seventh semester of a BS in Software Engineering at the University of Management and Technology in Lahore. My coursework covers data structures and algorithms, object-oriented design, databases and operating systems, and I write Java, C++ and Python for it.

Outside the classroom I build complete applications, mostly in Python with Flask. Noozaib Fragrances

Pre-launch · production hardening and deployment planning

A fragrance e-commerce application for the Pakistani market, covering the path from browsing the catalogue to placing and tracking an order, with an admin area for running the shop.

  • Catalogue with categories, customer accounts, cart and checkout
  • Email and Google sign-in, session invalidation and rate limiting
  • Admin area for products, orders, coupons and reviews, plus coupon and welcome-discount logic
  • Order stock handling, CSV export, web push notifications and a health-check endpoint
  • Alembic migrations with SQLite-to-PostgreSQL copy tooling, and a pytest suite of about twenty test modules

Stack: Python, Flask, SQLAlchemy, Alembic, PostgreSQL, Jinja2, JavaScript, pytest

My contribution: Developed the application end to end, from the data model and storefront to authentication, security hardening and tests.

GoldAI_Bot

Research prototype · paper trading only

A market-analysis tool that studies gold price data from MetaTrader 5 and records what a rule-based decision engine would have done, so ideas can be judged against history.

  • Market data, multi-timeframe and market-structure analysis
  • Economic-calendar, news and FOMC reaction analysis
  • Decision engine producing BUY, SELL or WAIT with reference levels, and a classifier that explains WAIT decisions
  • Paper outcome tracking and historical validation, with unit tests

Stack: Python, pandas, MetaTrader 5 API

My contribution: Designed and built the analysis pipeline, decision logic and validation tools. The code places no broker orders and the project makes no profit claims.

Stack: Python, Flask, SQLite, Alembic

My contribution: Designed the architecture and built the dashboard, workflow stages and approval gate.
